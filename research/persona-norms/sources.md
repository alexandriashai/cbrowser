# Sources

Every number in README.md comes from one of the sources below, retrieved on
2026-10-22. A source counts as retrieved only if it was opened that day,
through PubMed (metadata, abstract or PMC full text), Europe PMC full-text XML,
a publisher or repository PDF, or a web page. Nothing is quoted from memory.

**How each source was read.**

- The **Access** line says what was open. *Abstract* means only the abstract was
  seen, and only abstract statements are used from that source.
- **Read by** says who read it:
  - **lead**: the author of this README read the number at the location given.
  - **sub-agent**: one of four parallel research agents in the same session read
    it, and the lead did not reopen that location.
- Values in the norm-implied ranking and the 0.15 flags were all read by the
  lead.

**How the list is ordered.** Sources are grouped by the deliverable that uses
them most, in alphabetical order within each group. DOI and PubMed IDs are as
PubMed returned them.

**Count.** 63 sources:

- 51 supply a number used in README.md.
- 6 supply only a direction or a null finding: Ashwin 2017, Bowler 1994,
  Castle 2012, Jin 2023, Rizzo 2009 and Shamosh 2008.
- 4 name an instrument or a definition: AAIDD FAQ, Doherty 1997, McKnight 2002
  and Smith 2008.
- 2 are context or a negative finding: Eisenberg 2018 and Modic 2018.
